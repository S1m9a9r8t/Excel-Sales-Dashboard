# Excel Sales Dashboard Project

## Project Overview
This project focuses on analyzing Bike sales data and building an interactive dashboard using Microsoft Excel.

The purpose is to transform raw sales data into meaningful insights that support business decision-making.

## Key Insights
-Male customers who purchased bikes had a higher average income (60,124) than female customers who purchased bikes.
-Middle-aged customers recorded the highest number of bike purchases compared with adolescents and older customers.
-Customers commuting 0–1 miles had the highest number of bike purchases, followed by those commuting 2–5 miles.
-Customers commuting more than 10 miles showed relatively fewer bike purchases than customers with shorter commutes.
-The dashboard allows users to explore purchasing patterns based on marital status, region, and education level using interactive filters.

##conclusion
-The analysis suggests that age, income, and commute distance are useful factors for understanding customer bike-purchasing patterns.
Middle-aged customers and customers with shorter commutes represent important customer segments.
